Política de Privacidade — Pong Mobile Pro

Atualizada em 21 de novembro de 2026.

O Pong Mobile Pro, do projeto Pitinga, é um jogo offline para Android, sem anúncios, contas ou compras internas.

Dados pessoais e transmissão

O jogo não exige cadastro, não coleta dados pessoais, não utiliza ferramentas de análise nem transmite estatísticas de jogo para servidores.

Dados locais

As preferências de cores, tamanho da bola e das raquetes, modos de jogo e recordes são guardados exclusivamente no armazenamento local do aplicativo, no aparelho do jogador. Não são associados a uma conta e não são compartilhados com terceiros. Ao desinstalar o aplicativo, esses dados locais podem ser apagados pelo Android.

Publicidade

O Pong Mobile Pro não possui SDK de publicidade nem exibe anúncios.

Exclusão e alterações

Não mantemos dados pessoais do jogador em nossos servidores. Os dados locais podem ser removidos pelo usuário ao limpar os dados do aplicativo ou desinstalá-lo. Caso as funcionalidades relacionadas à privacidade mudem, esta política será atualizada.

Contato

Para dúvidas, utilize as solicitações públicas do repositório oficial.
